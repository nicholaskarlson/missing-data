NEKpress Research: Proof-First Guides

Follow an imputation from start to finish

Private calibration pilot. This verifies regression MI on a fictional continuous response. It is not the completed Unit 5 case and does not impute Tonmick stress. Units 1–6 and 9 now have complete reader packages; Unit 5 supplies the bounded Tonmick case and preserves a model warning.

Question and target

How does a stated normal-regression imputation procedure produce a pooled slope and interval? The target is the model's population conditional slope of y on x. It is a different target from the finite invited-roster stress mean. The 32 calibration records have fully observed x, 24 observed y values and eight blanks. No complete-y answer file exists.

The model assumes independent normal errors with constant variance and ignorable response given x. The fixed teaching pattern does not prove these assumptions. With only y missing, observed-case regression is a useful baseline under this model; MI need not improve its precision.

Inputs

  • Raw calibration records
  • Model, variance and failure contract
  • Indexed primitive normal draws
  • Data dictionary

Run

Use the setup instructions for Python 3.10–3.12 and NumPy 1.26.4. From the companion folder, choose new output paths:

python scripts/check_regmi.py --numeric --outdir build/regmi-python
python scripts/check_regmi.py --base-r --outdir build/regmi-three-route

The second command needs base R, without add-on packages. No World checkout or document renderer is used.

Inspect

Open report.json and the keyed CSV outputs in your chosen folder. The routes independently fit the observed regression, draw variance and coefficients, complete missing responses, fit each completed regression and pool its slope/variance. The checker compares all 811 keys, including all 640 completed values and every original observed response.

  • fit/: observed fit and covariance factor inputs.
  • imputation/1/: first posterior draw, completed records, slope Q and variance U.
  • pool/: pooled slope, W, B, T, Monte Carlo SE, finite-df FMI, adjusted Student-t interval.

P003 has x = −1.35 and a blank y. Its first completion is about 0.707620. The pooled slope is about 0.904352; the adjusted nominal 95% interval is about 0.714555 to 1.094149. Monte Carlo SE is about 0.011959, distinct from the scientific SE of about 0.089313.

Audit the conclusion

These outputs verify the declared calibration arithmetic, not a missingness assumption, real-world effect or coverage guarantee. Deterministic prediction fills give a smaller naive variance here. The MI result is not more precise than the observed-case baseline. Neither comparison is a ranking against unseen truth.

More imputations reduce simulation noise; they do not add responses or fix a false model. Twenty is an engineering count, not a universal recommendation. A bounded stress-score application requires its own support-respecting model and a variance matched to its actual target. Do not clip normal draws to make them look like item scores.
