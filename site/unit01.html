NEKpress Research: Proof-First Guides

Who is missing?

Audit the people and items behind a reported stress mean.

Numerical companion. This numerical route is implemented for review. The book's principal exercises and solutions remain in the private reader. All study records are fictional.

1. Name the target

Target B8-T01 is the mean full five-item baseline stress score for all 1,600 invited entrants, with equal weight per person. Reverse the fourth raw answer as 6 − st4 before scoring. A complete observed score requires all five answers. The target concerns the measured score at the declared baseline administration, rather than a latent trait.

Before running anything, decide whether a mean from complete surveys alone answers that population question. Write down what would connect those observed scores to the missing scores.

2. Use the ordinary inputs

The invitation frame supplies every eligible ID and response status. The baseline survey supplies returned stress answers. The scripts join by student_id and preserve the full frame.

  • Invitation frame (CSV)
  • Baseline answers (CSV)
  • Variable dictionary
  • Scoring, support and precision contract

No complete-roster stress file or author-only reveal enters this calculation. Numerical reference tables are read by the checker after each independent route finishes.

3. Run the audit

From the companion folder, use Python 3.10–3.12 and NumPy 1.26.4. A first-time setup is:

python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/check_unit01.py --numeric

This runs NumPy and standard-library Python independently. If base R is installed, add the third route:

python scripts/check_unit01.py --base-r

No add-on R packages, private checkout, World generator or document renderer are needed. Follow the README for the other numerical cases. A later identical run revalidates its existing outputs before reuse; a changed or incomplete attempt is recomputed.

4. Inspect the records

The command prints an output folder and writes its location in build/unit01-audit/current.json. Open that folder's summary.csv and people.csv. Keep IDs and five-bit patterns as text when importing into a spreadsheet.

InspectWhat it should preserve
people.csvAll 1,600 invitees, observed-item counts, keyed sums, blank incomplete full scores and five-bit patterns.

summary.csv1,067 complete scores; 5,934 observed items; complete_mean about 2.934; item_lower 2.44675 and item_upper 3.47975.

Every route must agree on the summary and every retained person record. If a route fails, retain the whole log and correct the cause before interpreting results.

5. Conclude, then question the claim

The mean 2.934 describes complete-score respondents. It is not automatically the invited-population mean. Partial records still contribute observed answers: holding those fixed and allowing every missing keyed answer to range from one to five places the target mean between 2.44675 and 3.47975.

These are logical support limits, not 95% confidence limits. They add no missing-at-random assumption and identify no bias direction. A point estimate for everyone invited needs more observations or a defensible link from observed to missing scores. Numerical agreement verifies arithmetic, not that link.

For a stronger next study, define a probability follow-up of original nonrespondents, retain its selection probabilities, distinguish follow-up response from selection, and document measurement-time and mode limitations. Administrative outcome linkage answers a different question from missing baseline stress.
