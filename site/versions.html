Check your download

Put the ZIP and SHA256SUMS in the same folder. On Linux run:

sha256sum -c missing-data-v0.1.0.SHA256SUMS

On macOS use shasum -a 256 -c missing-data-v0.1.0.SHA256SUMS. In PowerShell use Get-FileHash .\missing-data-v0.1.0.zip -Algorithm SHA256 and compare with the downloaded checksum. The numerical verifier checks the extracted package's separate internal inventory.

Use an edition-matching copy

Prefer a named release to a moving main-branch download. Keep the ZIP, checksum and output reports with your work. Corrections receive a new version and an explanation of the affected cases. Existing release assets and tags should not be replaced.

Cite the materials

Karlson, Nicholas Elliott (2026). Missing-Data Reasoning with Statistics: Numerical Companion, v0.1.0. https://github.com/nicholaskarlson/missing-data. See CITATION.cff for machine-readable citation information. No DOI is claimed.

Report an error

Use the repository issue tracker. Include the release, unit/case, command, output key or row, runtime and log. Explain whether the concern is arithmetic, data definition, assumptions or interpretation. A numerical correction and a changed scientific question need different explanations.

Optional reveal

No reveal dataset is included. A first-edition decision on any separately reviewed, matching-measurement comparison remains. The ordinary calculations do not require it or access to the private World generator.
