Unit 7: Likelihood Under Missing at Random

Numerical companion. All records are fictional. Use partial answers as marginal likelihood factors, check identification and maximization, and keep observed information distinct from fractional completion.

Run

python scripts/check_unit07.py --base-r --outdir build/unit07-review

Use a new output folder. NumPy 1.26.4, Python 3.10–3.12 and base R reproduce 709 values and 1,600 audited person rows. No renderer is required.

Inspect

Read group/11/start/0/sweep/, group/11/information/, model/, naive/ and toy/ridge/ keys. The person file retains 2,373 raw answers and 1,191 known events. Plug-in probabilities are separate from raw values.

Conclude and question

B8-M07 is a fixed-composition model probability: estimate 0.206158, observed-information asymptotic SE 0.011818. The approximate Wald interval 0.182996–0.229321 is conditional on the joint and sufficient observation assumptions and repeated-data regime. It is not an interval for the realized finite B8-D06 fraction. EM convergence does not prove identification or MAR. A flat-ridge toy gives stable but different p11 values.
