Reproduce results

First download and extract companion v0.1.0. Work in its root folder, where README.md, requirements.txt and scripts/ appear together. Keep the extracted files unchanged; the verifier checks their inventory and hashes.

Install the declared environment

Use Python 3.10–3.12, with 3.12 recommended for these commands, NumPy 1.26.4, and base R with Rscript on your command path. No add-on R packages or document renderer are needed. Download software from Python and CRAN if needed.

Linux or macOS
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
Rscript --version
Windows PowerShell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Rscript --version

For the following commands, replace python with .\.venv\Scripts\python.exe. If Rscript is not found, add your R installation's bin directory to PATH, then reopen the terminal.

Check one result first

python scripts/verify_companion.py --case unit01 --base-r --outdir build/unit01-first

A successful run ends with MISSING_NUMERICAL_OK cases=1 routes=3 implemented_units=12. Open build/unit01-first/report.json, unit01_stdlib.csv and unit01_stdlib_people.csv. The NumPy and R files provide the independent comparisons.

Find S1000118 in the person table. Its raw stress answers are 3, 4, 1, 2, 4. Reversing st4 gives 4, so the keyed sum is 16 and the full score is 3.2. A person without all five observed items keeps a blank observed full score. Compare this walkthrough with Unit 1 before interpreting the roster mean.

Check the complete collection

python scripts/verify_companion.py --base-r --outdir build/all-results

Success ends with MISSING_NUMERICAL_OK cases=16 routes=3 implemented_units=12. The sixteen numerical cases cover the twelve principal units, calibration and engineering/audit cases, and both extensions; the counts are not interchangeable. Read build/all-results/report.json and the route logs and CSVs beside it.

Choose a new output directory when repeating these commands. Existing directories are deliberately not overwritten. The Unit 1 guide also describes its separate verified-resume wrapper.

What agreement establishes

The checkers compare complete key inventories, declared row fields, preserved observed cells and finite numerical values using unchanged absolute and relative tolerances of 1e-11. Each analyzer reads the raw inputs and specifications itself. Reference answers enter only the checking stage.

A successful run reproduces the specified calculation. It cannot establish MAR, validate the Unit 5 item model, turn an assumed sensitivity shift into evidence, or certify a causal claim. Retain the target and Claim Audit when using the output.

If a check fails

Keep the full error and the new output directory. Check the software versions and whether the release files were edited. Re-extract the same release into a clean directory rather than refreshing its checksums. For an error report, include the release, case, exact command, runtime versions and log, with no personal or confidential data.
