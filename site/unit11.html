Sensitivity Analysis for MNAR

Fictional twelve-month wellbeing in the original 1,219-person randomized roster. This mean-sensitivity function predicts the realized assigned-score contrast D; the finite causal B8-T02 target remains distinct.

Run python scripts/check_unit11.py --base-r --outdir build/unit11-review from the companion root after setup, using a new output folder.

Reverse wb4, compute observed college/arm/item mean anchors, and apply separate requested deltas to missing keyed-item means only, clipped to 1–5. Positive delta means higher wellbeing. Original observed answers, blanks, assignment and college shares remain. Zero delta is an unverified mean restriction.

Inspect unit11_stdlib.csv and its _people.csv, _cells.csv and _grid.csv files. Three routes check 467 summaries, 1,219 people, 160 cells and 81 scenarios. The grid file encodes deltas in half-points: divide the first two columns by two.

Reference D is 0.104568. Control delta +0.5 and offered delta -0.5 give -0.240425. Offered-only adverse shift reaches zero at 0.328663; the symmetric adverse path reaches zero at t=0.303103, or 0.151551 per arm. The continuous piecewise-linear paths respect clipping. The teaching offered-only path has no tipping point, represented by defined=0 and no t key.

Extreme grid values reproduce Unit 9 realized-D support [-1.281362,1.478587]. These are not confidence limits. Grid choices are not probabilities, missing means are not observed categories, and no interval or causal-sign inference is added. Unit 5's separate model warning remains.
