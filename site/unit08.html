Unit 8: Weighting for Nonresponse

Numerical companion. All records are fictional. Retain the equal-person five-item stress target B8-T01, separate survey return from full-score availability, and audit calibration and trimming.

Run

python scripts/check_unit08.py --base-r --outdir build/unit08-review

Use a fresh output folder. Python 3.10–3.12, NumPy 1.26.4 and base R reproduce 260 values, 1,600 person rows and all 24 hypothetical masks. No renderer is needed.

Inspect

Read group/, design/, confidence/, trim/ and toy/ keys. All 5,934 raw answers and 1,067 complete scores are preserved. Unknown full scores and ineligible analysis contributions stay blank. Weights sum to 1,600 and match four group totals.

Conclude and question

The weighted point is 2.935850. Estimated SE 0.014933 concerns the declared uniform-subset response-selection model; the conservative range/Chebyshev interval 2.776438–3.095262 has at-least-95% coverage only under that model. Actual response was not randomized by this design. Logical item support 2.44675–3.47975 remains without it. Calibration does not prove absence of outcome selection; trimming changes composition and within-group recalibration undoes the simple cap. No trimmed interval or hidden Tonmick benchmark is supplied. Unit 5's separate scientific warning remains.
